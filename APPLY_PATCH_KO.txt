SEMI-ATLAS v1.11 덮어쓰기 패치

1) 현재 Git 프로젝트 폴더를 백업합니다.
2) 이 ZIP의 내용물을 Git 프로젝트 루트에 그대로 복사합니다.
3) 같은 이름의 파일은 '덮어쓰기/바꾸기'를 선택합니다.
4) 새 파일 HeroSlider.jsx, hero-process-*.webp, verify-interactions.mjs도 함께 복사되어야 합니다.
5) 실행:
   npm install
   npm run check
   npm run build
   npm run dev
6) 이상 없으면:
   git add .
   git commit -m "Add hero slider and navigation interactions"
   git push
